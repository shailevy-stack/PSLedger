🩹 Restore expenses

Paste rows recovered from the Google Sheet's Log tab (via File → Version history) in the order Date Person Amount Category Description — exactly what you get by selecting the cells in Sheets and copying (tab-separated). One expense per line. Header row is optional and auto-skipped.

This merges recovered rows into the live Firestore expense list — it does not overwrite anything. Rows that already match an existing expense (same date, person, amount, category, description) are skipped automatically, so it's safe to paste more than you need.
